# Quick SDF Paint 0.8.0

0.8.0は、真横からのライトを直接確認・修正できる中央キーと、制作進行度で読みやすいタイムラインを追加した更新です。

## 9キーのライトスイープ

- 新規Projectは0、12.5、25、37.5、50、62.5、75、87.5、100%の9キーで始まります。
- 中央50%は、真横方向から直接法線ガイドをベイクした `Side Light 90°` キーです。
- Studioはこの中央キーを選択して開きます。
- 0%の `Light Starts`、50%の `Side Light 90°`、100%の `Full Light` は削除・移動できません。
- 真横光はライト方向を表します。白黒の面積が必ず半分になるという意味ではありません。

## タイムライン

- 通常表示を0～90°から0～100%の制作進行度へ変更しました。
- 50%のプレイヘッド、`Side Light 90°` マーカー、中央サムネイルが同じ位置に揃います。
- タイムラインの割合は物理角度ではありません。実ライト角はドラッグ中のBlenderステータス表示で確認でき、中央は厳密に90°です。
- スクラブは連続Previewだけを更新し、移動だけではキーやImageを作りません。

## 必要な時だけ増えるCustomキー

- キー間では補間結果を一時Canvasとして表示し、その見た目のままペイントできます。
- 8-bit値が変わっただけではCustomキーを作りません。0.5境界を実際に越え、書き出し結果へ影響する変更が生じた時だけ確定します。
- 低Strengthの複数strokeは一時Canvasへ蓄積され、境界を越えた時点でまとめてCustomキーになります。
- Customキーの作成、筆跡、Coverage、Smart Paintによる伝播は1回のUndo／Redoで扱います。
- 片側最大16キーの上限は変わりません。

## 変更していないもの

16-bit RGBA PNG、lilToon向け既定Packing、Custom Packing、SDF距離補間、非破壊Export Repairの仕様は従来どおりです。

## 対応環境

- Blender 5.1／5.2 LTS
- Windows x64
