# 光照时间轴 UI 重构

状态：待实施

## 结论

采用原版 `jayanam/bl_ui_widgets`，在项目内维护轻量 fork，自行适配 Blender 5.1／5.2。使用直观的自绘 UI，而非原生 Panel／UIList；不需要曲线编辑器。

## 简要细节

- UI 仅需一个光照进度滑块，以及一个可增删关键帧、按光照进度排序的缩略图列表。
- 拖动滑块实时预览，松手落定；选中列表项时滑块跳到对应位置，当前项高亮。
- 复用现有角度数据、预览、吸附与小尺寸缩略图缓存；只移植必要控件及绘制、事件基础设施。
- 业务接线：拖动调用 `studio.seek_preview()`（保留 30Hz 节流），松手调用 `studio.settle_seek()`，选择调用 `studio.select_paint_key()`；显式增删入口为 `quicksdf.key_add`／`quicksdf.key_delete`。
- 保留每侧最多 16 个 key、同侧角度不重复、0／45／90 锚点不可删除的约束。
- 添加按钮的初始化语义待确认：现有 `key_add` 默认烘焙（可复制当前 key）；空位绘画则先插值准备临时 Canvas，跨越二值边界后才提交正式 key。
- 兼容修复重点：移除 `bgl`、更新 shader／纹理／文字 API，统一 region 坐标，处理 UI 缩放、事件隔离和退出清理。
- 保留上游许可与版权声明，记录来源版本及修改。
- 宿主区域另行决定；本共识未确定替代节点编辑器的具体方案。
