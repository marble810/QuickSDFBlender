# 光照时间轴 UI 重构

状态：已实施（5% 红区斜率与矩形手柄微调按用户要求仅重载、不测试；此前 Blender 5.2 红区松手／退出回归通过，增删弹窗未完整验证）

## 结论

采用原版 `jayanam/bl_ui_widgets`，在项目内维护轻量 fork，自行适配 Blender 5.1／5.2。使用直观的自绘 UI，而非原生 Panel／UIList；不需要曲线编辑器。

## 简要细节

- UI 仅需一个光照进度滑块，以及一个可增删关键帧、按光照进度排序的缩略图列表。
- 拖动滑块实时预览，松手落定；选中列表项时滑块跳到对应位置，当前项高亮。
- 复用现有角度数据、预览、吸附与小尺寸缩略图缓存；只移植必要控件及绘制、事件基础设施。
- 业务接线：蓝区拖动调用 `studio.seek_preview()`（保留 30Hz 节流），松手调用 `studio.settle_seek()`，选择调用 `studio.select_paint_key()`；红区调用 `update_endpoint_preview()`，松手及 Gizmo 退出保留当前物理偏航和预览，不落键。显式增删入口为 `quicksdf.key_add`／`quicksdf.key_delete`。
- 每侧最多 16 个 key、同侧角度不重复；`DEFAULT_KEY_ANGLES` 原生九个角度全部禁止删除与改时，UI 禁用相关按钮，操作层也强制校验。非默认角度的新增帧仍可删除与改时；不自动补回此前已删除／改时的默认帧。
- 添加按钮复用 `key_add` 角度弹窗；显式新增帧改为同一编辑侧相邻已绘制 Display 的全分辨率 SDF LERP，按目标进度计算权重，不重新烘焙网格法线，也不修改既有帧。Base 同步从相邻 Base 插值；Coverage 继承两侧并包含结果相对当前生成层的差异，保留尚未物化 Coverage 的绘画内容。插值完成后保存并选中新正式帧。
- 新增前校验邻帧、分辨率、数量上限与角度重复，并先计算后插入，避免插值失败留下空帧；既有 Duplicate Current 操作保留。空位绘画的自动临时 Canvas／跨越二值边界后提交机制不变。暂不增加浮层复制按钮。
- 兼容修复重点：移除 `bgl`、更新 shader／纹理／文字 API，统一 region 坐标，处理 UI 缩放、事件隔离和退出清理。
- 保留上游许可与版权声明，记录来源版本及修改。
- 宿主确定为 3D Viewport 底部的 BlenderKit 风格自绘浮层；默认工作区改为 Canvas／3D 两栏，不再创建独立时间轴区域。
- 浮层整体尺寸为初始 MVP 的 1.5 倍；统一缩放因子为 `1.5 × preferences.system.ui_scale × 用户 Bottom UI Scale`（用户倍率默认 1.0，范围 0.5–2.0），使用 Blender 官方包含操作系统 DPI 与界面 Resolution Scale 的倍率，不额外乘 DPI／pixel_size。统一缩放文字、缩略图区域、按钮、滑块、边距与命中区域；空间半圆半径不受界面倍率影响。
- 浮层最大逻辑宽度为 1200（乘界面倍率）；自动避让工具栏与侧栏，缩略图中心按实际进度与 Slider 同一 X 坐标排布，端点为缩略图预留半宽，全部显示当前侧关键帧，不分页。
- 缩略图及其标签／边框缩至前一版的 75%，固定单行，中心仍严格对齐 Slider 角度，不上下错层。近邻卡片可重叠，当前选中帧绘制在最上层，重叠点击按最近中心选择。
- 窗口宽度／DPI 改变时重新计算布局；缩放变化使控件布局缓存失效。
- Quick SDF 侧栏最底部新增独立可折叠 `UI Settings`，无需创建项目即可调整整个底部浮层倍率；使用 AddonPreferences 跨项目保存，不修改 Blender 全局倍率或空间指示器半径。关闭 Blender 自动保存偏好时提供 `Save Preferences` 按钮。
- 已实施光照进度滑块：点击轨道、拖动 30Hz 预览、松手落定，ESC／右键取消；复用现有吸附与临时 Canvas 业务。
- 已实施按当前编辑侧／光照进度排序的缩略图条，选中正式帧使用实线高亮；游标和临时帧空心标记独立显示，状态区分 Paint／Preview／Preparing／Pending paint／Limit。
- 默认九个角度阶段的缩略图使用绿色边框；当前选中帧另加蓝色外框，不覆盖绿色边框。九个默认角度均受删除与改时保护。
- 轨道标记所有正式关键帧的实际位置；新增／删除按钮位于浮层标题行，锚点和达到上限时禁用相关操作。
- 删除正式帧前确认，提示会清除 Quick SDF 绘画撤销历史。没有关键帧拖动改时或曲线编辑。
- 轨道物理偏航覆盖 180°→0°，采用分段非线性 UI 映射：左、右红区各占 5%，蓝区占 90%；180°→130° 与 50°→0° 各占 1%，130°→120° 与 60°→50° 各占 4%，各段内线性，优先保证靠近绘制端点的预览操作精度。去掉 `Preview only` 字样；仍禁用加号、不选中关键帧、不创建临时帧，延迟预览刷新也不得覆盖红区结果。
- 滑块采用连续实色分区，透明控件背景不提交绘制，移除中间黑线；手柄为跨轨道高度的矩形。
- 缩略图、刻度、手柄共享该映射；手柄文字显示实际偏航而非轨道空间百分比。箭头读取实际物理偏航，不读取压缩后的 UI 百分比；蓝区原有烘焙角度与吸附行为保持不变，不修改烘焙公式、正面轴或导出编码。
- 缩略图继续使用 96×64 RGBA8 衍生纹理；修复 Blender 5.1 仅接受 FLOAT 上传缓冲的问题、显式绑定图片 shader，以及图片区域占用进度标签空间的问题，不上传完整 Display 纹理。
- 现有独立面板绘制、事件及三区域布局代码保留为 legacy 实现，暂不删除。
