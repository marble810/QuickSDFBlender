# 光照方向指示器

状态：MVP 已实施（语法检查通过；Blender 当前场景已确认半圆与箭头显示，区域选择／撤销未完整验证）

## 最终方案

- 在 Quick SDF Studio 的 3D 视口绘制经过面部质心的世界 XY 半圆环，当前侧 RIGHT／LEFT 决定半圆朝向；短箭头从圆环指向质心。
- 圆环仍覆盖正后方 180° 到正前方 0°。箭头不走这条显示半圆，而落在实际烘焙光向上：0% 为 120° 斜后，50% 为 90° 正侧，100% 为 60° 斜前。180° 纯黑和 0° 纯白只在导出阈值图时补上，不是烘焙关键帧。
- 圆环与箭头使用同一正交 XY 参考系，不直接投影 3D 光照向量，避免倾斜角色丢失进度变化。前方轴投影退化时使用 Up 的 XY 投影作为参考。
- 半圆每 22.5° 放置一个向外的径向刻度，共九个；0°／90°／180° 刻度加长，其余使用短刻度，无文字标签。
- 箭头仅单向读取当前光照进度／绘制侧，与滑块及关键帧选择同步；不反向控制光照，不支持拖动，也不改写材质或光照参数。
- 默认中心范围为现有 Face Area；用户在 3D Viewport 的 Edit Mode 选择面部网格面，单独保存中心范围，不依赖 UV，不改变绘画、烘焙或导出区域。
- 采用评估后 3D 三角形的世界空间面积加权质心，半径为所选区域最大 XY 径向距离的 2.4 倍（原 MVP 半径 ×2）。
- 中心范围存储为项目 UUID 命名的 INT/FACE 属性（0／1），支持保存与撤销；属性无法通过修改器评估时隐藏指示器，不静默改用全 Mesh。
- 仅 GPU 视口绘制，不创建场景对象；遵循现有 Studio／辅助 Mask／Gizmo 显示条件。第一版保留底部滑块，不支持箭头拖动。

## MVP 操作

1. 已创建项目的目标 Mesh 在 3D Viewport 进入 Edit Mode，切换到面选择模式。
2. 选中面部网格面。
3. 在 3D Viewport 侧栏 Quick SDF > Light Indicator Center 点击 Use Selected Faces as Light Center。
4. 返回 Object Mode，打开 Quick SDF Paint，通过底部滑块查看箭头方向。
5. 同一面板中的 Use Face Area as Light Center 可清除自定义范围。

## 暂不包含

- 自动切换编辑器／模式的选择向导、箭头拖动、有效区间高亮。
- 独立显示开关、区域属性失效的专门 UI 提示。
